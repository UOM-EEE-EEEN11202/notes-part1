Agentic coding tools
====================

Agentic coding refers to using AI agents to write and test you code for you. It is a type of :ref:`AI tool <ai_tools>`, with such importance that it gets its own page.

An agent is an autonomous AI that can take many actions by itself. It can write code, run the code, test the code, iterate the code, and so on. In agentic coding you may have multiple AI agents that work together. For example, there may be one agent that write the code, and then another which runs the code and tries to break it in order to help find any bugs. Rather than entering multiple prompts to guide the work and in more chat like and interactive manner, in agentic coding you focus on giving the agent a goal, and it will work out how to achieve that goal.

We started our discussion on software development tools with :ref:`integrated development environments (IDEs) <ide>`. There are *harnesses*, such as :ref:`OpenAI Codex <>`, :ref:`Claude Code <>`, and :ref:`GitHub Copilot <>` which connect agentic tools to the IDE and let agents run on your code. These agents then go far beyond a simple chat interface. Agentic tools can plan tasks, and take multiple steps in one go. 

There are also versions of the agentic tools, such as :ref:`OpenAI Codex <https://chatgpt.com/codex/>`, :ref:`Claude Code <https://claude.com/product/claude-code>`, where you never see the IDE. Essentially you provide a goal, and the agent works on your request making code in the background. You just get the result back, potentially never seeing the code itself. Say, for example, I have some data from an experiment I want to plot. You don't per se need to see the code for this. You can see the plotted result and and check that's what you want. For more critical tasks, it's highly likely that you'll want to see, and interact with, and modify the code, rather than having the code only in the background. 

At the time of writing, in 2026, agentic tools and their use is still evolving. It's likely that they will see greater use over time. 

.. admonition:: This course

   We don't cover agentic tools in this course. Our aim is for you to understand programming and writing code so that you have the fundamental knowledge in place, before then using AI to accelerate your work. In the exam in particular we will expect you to be able to write code without relying on a coding harness.
