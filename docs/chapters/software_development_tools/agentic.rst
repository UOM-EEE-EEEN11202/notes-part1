Agentic coding tools
====================

Agentic coding refers to using AI agents to write and test you code for you. It is a type of :ref:`AI tool <ai_tools>`, but is such importance that it gets its own page.

An agent is an autonomous AI that can take many actions by itself. It can write code, run the code, test the code, iterate the code, and so on. In agentic coding you may have multiple AI agents that work together. For example, there may be one agent that write the code, and then another which runs the code and tries to break it in order to help find any bugs. 

We started our discussion on software development tools with :ref:`integrated development environments (IDE) <ide>`. There are *harnesses*, such as :ref:`OpenAI Codex <>`, :ref:`Claude Code <>`, and :ref:`GitHub Copilot <>` which connect agentic tools to the IDE and let them run on your code. They go beyond a simple chat interface. Agentic tools can plan tasks, and take multiple steps in one go. 

There are also versions of the agentic tools, :ref:`OpenAI Codex <>`, :ref:`Claude Code <>`, where you never see the IDE. Essentially you provide an input, and the agent works on your request making code in the background, and you just get the result back. Say, for example, I have some data from an experiment I want to plot. You don't per say need to see the code for this. You can see the plotted and and check that's what you want. For more crticial tasks, it's highly likely that you'll want to see, and interact with, and modify the code, rather than having the code only in the background. 

At the time of writing, in 2026, agentic tools and their use is still evolving. It's likely that they will see greater use over time.
